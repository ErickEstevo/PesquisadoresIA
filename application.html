Some Professions and Their Salaries

Data Scientist

Mines, organizes, and translates mountains of data into actionable answers. This professional creates predictive models and uses artificial intelligence to uncover hidden patterns, clearing the path for strategic decisions.

Machine Learning Engineer

Creates and runs machine learning algorithms. The focus here is on building intelligent systems that learn on their own from the information they receive, improving their own performance without needing constant intervention.

Prompt Engineer

It designs, tests, and refines commands to extract the best possible results from generative AIs. Basically, it translates what we want into the language that the machine understands.

Wage

A Data Scientist earns an average of R$11,099.46 per month; a Machine Learning Engineer earns an average of R$8,671 per month; and a Prompt Engineer earns an average of R$15,000 per month.
